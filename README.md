# Note-Taking-API-Project-Group-4

A simple RESTful note taking API for creating, reading, updating and deleting notes. 
Built with **Node.js** and **Express.js**

## Tech Stack
- Node.js
- Express.js
- JavaScript
- Postman (for API testing)

## Installation
1. Install dependencies
2. Create a `.env` file
3. Start the server

## Setup
```bash
npm install
npm run dev
